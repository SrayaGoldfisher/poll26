חיבור ל-Firebase והעלאה ל-GitHub Pages

הקלפי מחוברת ומסונכרנת בזמן אמת כל הצבעה נשמרת בענן ומתעדכנת אצל כל החברים
שיטה 1 (הכי מהירה – ללא עריכת קוד!)

הדבק כתובת Firebase Realtime Database או firebaseConfig:

אם תדביק כאן את כתובת ה-Realtime Database שלך מ-Firebase (למשל: https://my-poll-default-rtdb.firebaseio.com), המערכת תצמיד אותה אוטומטית לקישור הוואטסאפ של הקבוצה (?room=...&db=...). כך כל חבר שילחץ על הקישור ב-GitHub Pages יתחבר ישירות לקלפי שלך!

שיטה 2 + מדריך העלאה ל-GitHub Pages ב-2 דקות
  1. ב-Firebase Console: צור פרויקט חינמי, הפעל Realtime Database (במצב Test Mode כך שניתן לקרוא/לכתוב) או Firestore Database + Authentication (Anonymous).
  2. הטמעה בקוד (אופציונלי): בראש אזור ה-<script> בקובץ זה מופיע המשתנה CUSTOM_FIREBASE_CONFIG — תוכל להדביק שם את ה-firebaseConfig שלך כדי שיהיה מובנה קבוע בקובץ.
  3. העלאה ל-GitHub Pages: העלה את הקובץ בשם index.html ל-Repository ציבורי ב-GitHub, היכנס ל-Settings → Pages, בחר בענף main ולחץ Save. תוך דקה תקבל קישור מוכן לשיתוף בוואטסאפ!

הגדרת קוד קלפי לקבוצת הוואטסאפ

כדי שהחברים בקבוצה שלך יצביעו לאותה תיבת קלפי פרטית משלהם, בחר שם או קוד לקלפי (למשל: KNESSET26 או MILUIM). הקוד מצורף אוטומטית לקישור הוואטסאפ!

הוספת פתק הצבעה מותאם אישית

רוצים להוסיף מפלגה שלא מופיעה ברשימה או פתק הומוריסטי פנימי של החבר'ה בקבוצה? הוסיפו אותו כאן והצביעו בו!

איך נשמרת האנונימיות המוחלטת?

הצבעה חשאית 100% ("מאחורי הפרגוד")

  • ללא פרטים מזהים: האפליקציה לא מבקשת ולא שומרת שם, מספר טלפון, אימייל או כתובת IP של המצביעים.
  • פתק בלבד בתיבת הקלפי: מה שנשמר ב-Firebase הוא אך ורק קוד הפתק שנבחר ומזהה אקראי חד-כיווני.
  • מניעת הצבעה כפולה: כל מכשיר מקבל אסימון הצבעה אנונימי חד-פעמי כדי שכל חבר יוכל להכניס מעטפה אחת בלבד לקלפי (עם אפשרות להחליף את הפתק שלו מאחורי הפרגוד אם התחרט).
