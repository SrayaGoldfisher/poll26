# 🗳️ קלפי וירטואלית אנונימית | סקר חברים לבחירות לכנסת ה-26 🇮🇱

ממשק אינטרנטי קל, מהיר ואנונימי לחלוטין לביצוע מדגם בחירות בקבוצות וואטסאפ של חברים, משפחה או צוותים — ללא צורך בהתקנת אפליקציה, הרשמה או הזדהות.

🔗 **קישור ישיר לקלפי:** [https://srayagoldfisher.github.io/poll26/](https://srayagoldfisher.github.io/poll26/)

---

## ✨ מה כולל הממשק?

* **🔒 100% אנונימיות ("מאחורי הפרגוד"):** המערכת אינה מבקשת או שומרת שם, מספר טלפון, אימייל או כתובת IP. כל מכשיר מקבל מזהה אקראי חד-כיווני (`localStorage`) כדי למנוע הצבעות כפולות, תוך אפשרות לעדכן את הבחירה האישית מאחורי הפרגוד.
* **🗂️ מגש פתקים אותנטי ומלא:** עיצוב נאמן לפתקי ההצבעה הרשמיים בישראל, כולל סינון מהיר בין המפלגות המרכזיות לכלל הרשימות המתמודדות לכנסת ה-26, חיפוש חופשי, ואפשרויות של **"מתלבט/ת"** או **"פתק לבן"**.
* **➕ הוספת פתק מותאם אישית:** אפשרות להוסיף פתק פנימי או הומוריסטי של החבר'ה בקבוצה שמופיע מיד במגש הפתקים של כולם.
* **🏛️ סימולטור 120 מנדטים בזמן אמת:** סנכרון חי (מבוסס Firebase Realtime Database) שמחשב אוטומטית את חלוקת 120 המנדטים של הקבוצה (כולל מתג למעבר בין "כל קול נחשב" לבין אחוז החסימה הרשמי – 3.25%).
* **🧩 מרכיבים קואליציה:** מחשבון אינטראקטיבי לבדיקת הרכבי קואליציה של 61 מנדטים מתוך תוצאות האמת של הקבוצה.
* **📲 שיתוף מובנה לוואטסאפ:** כפתורים ייעודיים לשליחת הזמנה לקלפי ולייצוא דו"ח מדגם מעוצב להדבקה ישירה בצ'אט הקבוצתי.

---

## 🚀 איך משתמשים?

1. **נכנסים לקישור הקלפי:** פותחים את האתר מהנייד או מהמחשב.
2. **בוחרים קוד קלפי (אופציונלי):** ניתן להשתמש בקלפי ברירת המחדל (`KNESSET26`) או ללחוץ על **"החלף קוד קלפי"** כדי לפתוח תיבת קלפי נפרדת לקבוצה ספציפית (למשל `MILUIM` או `FAMILY`).
3. **משתפים בוואטסאפ:** לוחצים על **"שתף קישור לקבוצה בוואטסאפ"** ושולחים לחברים.
4. **מצביעים וצופים במדגם:** כל חבר בוחר פתק לבן, מכניס למעטפה הכחולה וצופה בתוצאות המתעדכנות בזמן אמת.
